## 1. UI 布局（2D 侧视）

顶栏：季节·日（如「春 12/30 · 年1」；内部 `dayInSeason` 为 0-based，显示 +1，见 [01 §2](01-time-season.md)）、天气、体感温度、里程、速度、**行驶日额度**（可用/已用或「今日推进已满」）、**核心六元**、装备入口、暂停/倍速。  
战斗编成 / 战前向导（暂停；与 [05 §6.2](05-combat.md) 对齐）：  
1. **编队**页：最多 4 套预设；上场名单 + 后备顺序  
2. **占位**页：前排 4 / 后排 4 槽位板（L3 另显车体区）  
3. **装备**页：远程 / 近战 / 防御  
4. **异能**页：上场觉醒者各声明至多 1 个（无觉醒者自动跳过）  
5. **战术**页：强攻 / 谈判 / 绕行 / 鸣笛 / 徒步撤离  
   - 无有效编队（无 `activeFormationId` 或上场 0）：**强攻灰显**；非战斗可用（`D=0`，见 05 §6.3）  
   - 鸣笛：`fuel < 2` 灰显  
   - 徒步撤离：核心六元未全 0 时灰显  
可跳过用默认（有有效编队时默认强攻；否则默认谈判）；向导顺序锁死为上列。
材料四元（废料/种子/试剂/织物）放在库存或工坊页，不进顶栏。区域气候因子可在天气旁短后缀。缺粮/缺水/高油耗闪烁。  
**油压 / 秋储 / 冲床 / 扩张挂车**：软规则与触发表见 **§4**；数据 [`data/hud_hints.json`](../data/hud_hints.json)。禁止只显示「燃料不足」。L6 提示进游戏：**暂缓·先不用**（不挡阶段一）。  


**进站发现面板（P0）**：主操作仍为修/挂；油紧时长编组对非白名单车型用次级样式 + `offerDeferCodes` 旁注（非硬禁，与 sim「ai_skip」区分，玩家可强行确认）。`cars≥12` 且油&lt;55% 时显示「长度即负担」一行。  
种植面板提供「供暖」开关（默认关），显示「0.30 燃料/节/日 → 粮产 0.50→0.95」；每年入冬首日强制提示并暂停一次，燃料不足时提前闪烁。
主视：三轨 + 列车 + 前方预警；世界为**连续铁轨侧视**（可卷动远景/废弃侧线装饰），逻辑区段由 [06 §0.2](06-region-events.md) 锚内容——禁止切成互不衔接的关卡小地图。短分岔（06 §1.4）用轨道路标 + 暂停二选一，不用开放节点图。  
侧栏：区域/三选一 | 成员（按 **生产/战斗/支援/杂工/无岗** 过滤与排序）/关系/岗位/编组。  
大人口（>20）默认折叠为轨道汇总 + 搜索，避免长列表拖死操作。  
岗位面板展示闭合 `job` id 名（种植/工坊/净水/药剂师/雷达员/动力看护/守卫/杂工/无岗）。  
搜索面板：grower/purifier 兼搜不空岗；crafter 兼搜提示「工坊工位今日不计产」；支援兼搜提示「医疗/雷达/动力当日空岗」（雷达空岗 → 该节不计入视野，见 03 §7）。  
顶栏/预警：显示 `effectiveVision` 简值；能见度差或雷达空岗时前方预警降级/关闭。
底栏：操作提示、搜索进度、最近日志。

| 操作 | 输入 |
|---|---|
| 切轨 | A/D |
| 加减速 | W/S |
| 停车 | 空格（长按） |
| 暂停 | Esc / P |
| 倍速 | 键 **1 / 2 / 3** → **1× / 2× / 4×**（[01 §2](01-time-season.md)） |
| 搜索 | E（先选点再**点名指派**可派人；无搜刮员岗） |
| 召回 | 任务面板一键召回 / **速度 > 8 km/h** 强制召回（[04 §5.7](04-population.md)） |

**时间 UX（与 [01 §2.2](01-time-season.md) 对齐）**：  
- 站内/事件/战斗/编队 → 暂停或 1×；纯巡航无车外任务 → 推荐 2×/4×（首次巡航可轻提示一次）。  
- `travelBudgetExhausted`：顶栏额度满 + 短日志「今日推进额度已用尽（仍前进则按停靠油耗）」；**不**再加里程。  
- 禁止 UI 暗示「当前时速 × 24h = 今日里程」。

搜索面板：可派人员列表（伤员灰显；`scavenge` 专长置顶并角标）；战斗入口只显示战斗小组编队；搬运队列显示杂工与临时堆。  

P0 反馈：搜索进度条、搬运完成飞入库存、召回提示、车灯、心跳音、撞击震屏、资源不足闪烁、额度用尽提示。

渐进引导：第 1/7/30/91 日用画面内提示，不用模态框。  
**区段事件窗**（阶段二）：见 [GODOT_ARCH §10 S2](GODOT_ARCH.md)——2–4 选项、暂停、立即/延迟分轨。

长车视图规则见 [列车](03-train.md) §8。

## 3. 内容模板

**事件卡**：ID、标题≤8 字、标签、条件、权重、正文 2–3 句（须具体人/物）、2–4 选项（即时+可选延迟）、日志句。

**成员生成**：出身 × 灾难经历 × 性格 → 背景 + `specialties[]`（0–2）+ 缺陷 + desire + 遗言两版。

首批量：事件 120、战斗目标模板 16、背景模块 200、遗言 200、创伤叙事 24、词条 12、车厢模板 9、异能 **11**、药剂 3 种、专长 7 种（见 04 §4.5）。  
**事件五语文案**：[`events_general.csv`](../data/localization/events_general.csv)（60）· [`events_season.csv`](../data/localization/events_season.csv)（40）· [`events_year.csv`](../data/localization/events_year.csv)（20）· `--bucket general|season|year`（见 [`localization/README.md`](../data/localization/README.md)）。

### 3.1 美术分层（定稿）

| 层 | 做法 |
|---|---|
| **世界** | 像素拼装：列车壳/设备、轨道、天气粒子（代码组合，控制车厢爆炸组合成本） |

## 4. 玩家软规则 · 提示与扩张 HUD

> 给玩家看的**软规则** + 程序触发表。**不**改 F04 / 季节乘子。  
> 灰盒：[10 §2](10-validation.md) · 冻结：[10 §1.1](10-validation.md) · configVersion **25**

### R1 · 油紧时你有五条路（勿只挂动力）

罐里油吃紧时，任选至少两条组合：

| # | 玩家说法 | 你在做什么 |
|---|---|---|
| 1 | 「先升动力科技」 | 单节动力也能更省油 |
| 2 | 「减速 / 停靠」 | 今日少跑，按停靠油耗熬 |
| 3 | 「挂货厢囤油」 | 罐容变大，秋冬才装得下 |
| 4 | 「再挂一节动力」 | 更省牵引，但多一节耗油 + 要工程师 |
| 5 | 「先把供暖关掉」 | 省独立油费；粮会变紧，看库存 |

**反模式**：油红了只找动力车挂上，其它全不管。

### R2 · 不是不能挂，是现在挂了过冬难

- 油大约不到半罐：优先 **货厢 / 动力 / 种植·净水**  
- 暂缓：**装甲**（特别耗油）、非刚需工坊/雷达  
- 已经很长（十来节以上）且油紧：新车厢默认「先看要不要」，不要见车就修挂  

文案口径：「长度即负担。」

### R3 · 秋储 → 冬雪原

| 何时 | 做什么 |
|---|---|
| 夏末～秋 | 开始囤油、囤粮 |
| 秋天 | 三选一里雪原值得去（有油点） |
| 雪原上 | 还有油可搜就多留；**搜空了就走**，别空等烧油 |
| 入冬 | 供暖有代价；知道「关供暖粮差、开供暖吃油」 |

### R4 · 先床后人

- 年 2 春～夏：先把床位扩到大约 **20**（休息车 + 生活科技）  
- 床不够时狂收留 → 过道挤、病、打不过  
- 新人先安顿，**别立刻塞进战斗名册**

### R5 · 造零件也吃油

油紧时可以暂停「造零件」日模式，把油留给跑路和供暖。工坊不是永远开着才对。

### R6 · 已经挂上可以甩掉

停靠且不是战斗/搜刮中时，可在列车视图 **遗弃指定车厢**（[03 §4.1](03-train.md)）：

- **适合甩**：装甲、雷达、工坊等非刚需高耗节；长编组油红时的减压  
- **慎甩**：唯一种植/净水/医疗、会跌破床位的休息节、最后一节动力  
- **有代价**：花零件切割 + 少量油，只得废料，**回不了发现池**

与 R2「暂缓新挂」成对：少加 + 可减。
