# 模块：战斗

> 所属层：玩法层  
> 依赖：人口（战斗名册/编队）、列车（车厢装甲）、资源（远程/近战/单兵防御）  
> 范围：核心循环含**战斗层级** L1/L2；丰富内容默认 Early Access 后（见验收模块）  
> 缩写：L1/L2/L3=战斗层级；`Lv`=异能/科技等级；字母战力式见 §7；总表 [architecture §8.1](../architecture.md)

---

## 1. 设计意图

决策型战斗，不做实时操作（倍速、长车列表、调度员定位）。  
每战保留 ≥2 条**有效**非战斗路径（红线 #8）。  
检定比 `D = P/(P+E)`：**不进**战斗层级 L2/L3 回合胜负（只比 `progressP/E`）；**仅用于** L1 成功检定与非战斗路径检定（§6.1/§6.3）。面板可显示 D 作相对优势参考。  
（此处 `D`/`P`/`E` 均为战斗式符号，**不是**「日 / 制作优先级 / 阶段零」。）  

战前可配置：**编队** + **占位** + **装备** + **异能**（有觉醒者时）。 
战斗中不微操走位；占位只影响结算权重。

**战斗只由战斗小组进行**：上场必须来自 `combatRoster`+编队；点名搜索者/杂工默认不上场。搜索与搬运见 [04 §5](04-population.md)。紧急征召只改名册不改原 `job`，须先召回车外任务（[04 §4.6](04-population.md)）。

## 2. 编队（Formation）

### 2.1 结构

```
Formation {
  id, name                          # 如「守车」「强攻」「夜战」
  slots: [ { memberId, slotId } ]   # 上场占位，≤8
  reserve: [ memberId ]             # 后备；伤亡后按序顶上
  defaultLoadout?: 覆盖成员默认装备
}
```

| 规则 | 口径 |
|---|---|
| 数量 | 最多 **4** 套编队预设（存档持久） |
| 人选 | 须在 [04](04-population.md) 战斗名册内；紧急征召临时加入名册后方可编入 |
| 上场 | `slots.length ≤ 8`；同一人不可同时在上场与后备 |
| 空槽 | 允许；按实际人数结算 |
| 编辑时机 | **任意暂停**可改；进战前可切换「本场编队」 |
| 默认 | 开局自动生成 1 套「默认编队」= 名册前 ≤8 人（开局至少含 04 §4.3.1 的 1 名 `guard`），占位见 §3 自动填；**同时** `activeFormationId` 指向该套（禁止开局无激活编队 / 上场 0 人） |

本场选用：`activeFormationId`；可「仅本场」打乱占位/人选而不写回预设（勾选「保存到编队」才写盘）。

### 2.2 与名册关系

```
战斗名册（谁可能参战）→ 编队（本场谁上场/后备 + 占位）→ 装备挂载 → 战术
```

名册可很长；编队是名册的**投影**。  
**无 `activeFormationId` 或上场 0 人**：禁止进入 L1/L2/L3 战斗检定与强攻；仍可选谈判/绕行/鸣笛/徒步撤离（§6.3）。L1 无「临时用名册前 8 人」兜底。

## 3. 占位（Slot / 站位）

不做实时地图；用固定槽位板。L2 与 L3 共用槽位 id，L3 可多开放「车体区」。

### 3.1 L2 槽位板（首发）

```
后排 rear_1  rear_2  rear_3  rear_4
前排 front_1 front_2 front_3 front_4
```

共 8 槽；每槽 0–1 人。编队 `slotId` 必须落在本表（或 L3 扩展表）。

| 排 | 输出修正 `posOut` | 受伤权重 `posDmg` | 适合 |
|---|---|---|---|
| **前排** front_* | ×0.95 | **×1.25** | 近战、单兵防御 |
| **后排** rear_* | 有远程则 **×1.15**，否则 ×1.00 | **×0.75** | 远程 |

同排左右无额外数值差（首发）；仅作站位展示与关系邻接（同排 ±1 槽视为相邻，用于救援叙事，不改公式）。

**自动占位**（一键）：有近战/无远程 → 优先前排；有远程 → 优先后排；防御不影响排，只影响装备。

### 3.2 L3 车体扩展槽

在 L2 八槽之上增加车体区（可空）：

| slotId | 含义 | 修正 |
|---|---|---|
| `bow` | 车头方向 | 同前排，对「撞车向」敌人 posOut×1.05 |
| `mid` | 车厢中段 | posOut×1.0，posDmg×1.0 |
| `stern` | 车尾 | 同后排 |
| `side` | 侧门/切口 | posDmg×1.15（危险但挡增援） |

L3 上场仍 ≤8；扩展槽与前后排共用人数池。

### 3.3 占位进公式

```
个体有效输出系数 = guardBoost × posOut
分摊受伤权重 = posDmg × (有 defense ? 0.70 : 1.0)
```

伤亡：按「分摊受伤权重」比例分配 `outE`（归一化后），不再纯平分。

## 4. 战斗装备三类

库存：[02](02-resources.md) `gear.ranged` / `melee` / `defense`。  
每名上场者最多各 1；未分配库存本场不生效。

| 类 | 挂载效果 | 战术倾向 | 战后耗损 |
|---|---|---|---|
| 远程 | `rangedBonus=8`；guardBoost×1.15 | 强攻、尸潮；宜后排 | 40% 耗 1 |
| 近战 | `meleeBonus=6`；guardBoost+0.1 | 守车；宜前排 | 25% 耗 1 |
| 单兵防御 | `defBonus=3`；受伤权重×0.70 | 任意 | 20% 耗 1 |

```
创伤惩罚 = min(0.40, 0.10 × (行动受限标签数) + 0.05 × (其它创伤标签数))
  # 标签来自 injuries[]；词条表 combat-trauma.json（叙事/适配）；数值只认上式
守卫个体 = (10 + rangedBonus + meleeBonus + defBonus)
         × (1−创伤惩罚)
         × (复仇?1.3 : 哀痛?0.9 : 1)    # 复仇覆盖哀痛；口径 [04 §6](04-population.md)
         × (有 combat_drill 专长 ? 1.05 : 1)
```

列车装甲 ≠ `gear.defense`。空手合法。配置 `gear.json`。  
战斗/岗位**无**等级成长轴；异能单局熟练度见 [04 §8.1](04-population.md)。

## 6. 三层结构与战前流程

| 层 | 处理 |
|---|---|
| L1 | §6.1 检定事件，非完整回合战 |
| L2 | §6.2 流程 + §7 结算 |
| L3 | 同引擎 + 扩展占位 + 多阶段/增援 |

### 6.1 L1（小股尸群）

不进占位板。须已有 **`activeFormationId`** 且上场 ≥1（与 §2.2 同一前提；否则只能走 §6.3 非战斗路径）。  
用该编队上场名单算 `P`（§7，A=0）。`E = 敌数 × 单体基础`（`combat.l1Unit`，基线 8）。切换激活编队后 L1 立即跟新。

```
successChance = clamp(0.35 + 0.45 × D, 0.15, 0.90)   # D=P/(P+E)
```

| 结果 | 效果 |
|---|---|
| 成功 | 跳过 L2；全体 mood +2；无伤亡；关联临时堆**保留** |
| 失败 | **系统 50/50**（非玩家选）：① 随机 1 名上场者轻伤（无行动受限）；或 ② 全体 hp −8。然后**玩家**选：「升级为 L2」或「撤离（同 §6.3 绕行失败）」 |

升级为 L2：开局 `progressP=progressE=0`（**不**继承 L1 失败）。  
**须重检编队**：按 [04 §5.6](04-population.md) 剔除**当前** `unavailable` 者（行动受限伤 / 发病 / `hp≤30%` / 召回途中）。L1 失败路径①「轻伤无行动受限」**不**自动 `unavailable`，仍可上场。若上场变为 0 → **禁止强攻**，仅非战斗路径（`D=0`）。可重开编队页改人选后再强攻。

### 6.2 L2/L3 战前（暂停）与战斗会话

```
1. 编队  2. 占位  3. 装备  4. 异能（无觉醒者可跳过）  5. 战术
强攻 → §7；谈判/绕行/鸣笛/徒步撤离 → §6.3
```

UI 页面对齐 [08 §1](08-presentation.md)。

**`taskState` 进出（与 04 §2 同一枚举）**：

| 时机 | 规则 |
|---|---|
| 确认强攻 / 进入 L1 检定 | 本场上场者 → `in_combat`；车外 searching/hauling 按 [04 §5.7](04-population.md) 强制召回 |
| 战斗/非战斗路径**结束** | 上场者：若未触发 §5.6 条件 → `idle`；否则 `unavailable` |
| 禁止 | 长期卡在 `in_combat`；读档若无完整 `CombatSession` 则强制清为 `idle` 并记日志 |

**`CombatSession`（战斗中存档必填；[09](09-data-platform.md)）**：

```
CombatSession {
  layer: L1|L2|L3
  round: 0..4                 # L1 无回合则 0
  progressP, progressE
  formationSnapshot           # 上场/后备 memberId + slotId
  declaredAbilities[]         # 本场已声明（含失败）
  encounterId / pointId?
  pathFlags                   # 如鸣笛失败 E×1.1
}
```

手动/铁人存档：须**暂停**；允许战中写盘，读档恢复到**当前回合开始前**（已结算 out 不回滚）。无会话时禁止残留 `in_combat`。

### 6.3 非战斗路径（红线 #8 闭环）

**无有效编队时（无 `activeFormationId` 或上场 0 人）**：本条仍可选；`D := 0`（不虚构名册战力）。  
检定：`pathChance = clamp(0.25 + 0.50 × D − 威胁修正, 0.10, 0.85)`（**D 仅用于本检定与 L1**，见 §1）  
威胁修正：变异体/首领 +0.15；普通尸群 0；谈判在有守卫名册时 −0.05（更易成功）。

| 路径 | 成功 | 失败 |
|---|---|---|
| **谈判** | 检定成功后**玩家**先选分支：① **免费放行**（mood +1）；② **买路**：仅扣**列车库存**（不可用临时堆）；`food 2` 或 `parts 1`，不足灰显；确认后立刻扣完；若扣后 `food==0` → 当日一次缺粮 mood 惩罚（同 WentZero 士气），**不**改 `foodZeroStreak`（streak 仅日结）。mood +3；本段 `raidWeightDelta -= 0.1`（掠夺/扫荡类事件权重，[06 §3](06-region-events.md) 消费；驶离本段清零）。均跳过战斗，临时堆**保留** | 有有效编队 → 强制转入 §7 强攻，开局 `progressE += 0.15`；**无有效编队 → 改按绕行失败结算**（禁止无编队进强攻） |
| **绕行** | 跳过战斗；可继续驶离；写入本段 `segmentFuelSurcharge=+0.05`（乘在 F04 `regionFuelMult` 侧，驶离本段清除；不叠多层）；临时堆**保留** | 全体 hp −15，20% 一人获行动受限；死因事故；临时堆 **50% 被夺** |
| **鸣笛** | 须 `fuel ≥ 2`（百分点）否则灰显不可选；成功：燃料 −2%；惊吓驱散；临时堆保留 | 同绕行失败，但临时堆保留；若再战则敌方本场 E ×1.1 |
| **徒步撤离** | 仅核心六元（food/water/fuel/parts/medicine/crystal）**当前均为 0** 时可选；跳过战斗；强制停车 1 游戏日；临时堆**放弃（视为被夺）** | 同绕行失败 + 临时堆被夺 |

**徒步撤离 vs 燃料失败**：撤离只解决本场遭遇，**不**清除 [02 §9](02-resources.md)「燃料=0 连续日」计数；日结仍按 07 优先级 3 判定失败。燃料已为 0 时撤离成功仍停在原地，须靠事件/搜刮补燃料。

失败且未再战：不记「战败」，但绕行/撤离失败的夺堆按上表。 
**平局撤退**（§7）：等同「弃物撤退」——关联未搬临时堆**允许被夺**（默认夺 100%，可事件减半）。

## 7. 战力与结算（战斗层级 L2/L3）

```
# 字母仅本战力式；勿与阶段零 A/B、制作 P0、异能 Lv 混读
B  = Σ守卫个体 + 装甲战力值          # 装甲战力 = 12×armorCars + 4×armorTechLv
A  = Σ(本场成功异能的战力贡献)       # 权威表 04 §8.3；≠ 阶段零「零 A」
    # 例：屏障 +15；感知 +B×10%；冲击波 +12；控物 +8；裂甲 +4；甲壳 +5
    # 静默：战斗层级 L2 无增援时 A+=6（异能等级另算）；勿与异能 Lv2 混淆
    # 治愈 / 鼓舞 / 急援等可不加 A，走其专用效果
P0 = B + A                           # 战力式 P0；≠ 制作优先级 P0
P  = P0 × relationMult               # 04 §6；默认 clamp ±20%；鼓舞异能 Lv1 ±25% / Lv2 ±28%
E  = 敌数 × 单体基础 × (1+0.15×(年份−1)) × 类型系数
D  = P/(P+E)                         # 检定比，非胜率；≠「日」
```

异能分系、**催化药剂**消耗与失败率以 [04 §8](04-population.md) 为准；本模块只执行 hooks（战力 A、outP、减伤、增援、急援等）。声明时扣 `potion.catalyst`（及 heal 的药），**不**扣晶核。

禁止 `6×weaponKits`。  
**装甲进战斗的唯一项**：战力值 `12×armorCars + 4×armorTechLv`（[03 §6.4](03-train.md)）→ 加进 `B`。  
**`trainDR` 不进本式**：只用于碰撞/碾压车体；禁止对 `outE` 再乘 `(1−trainDR)`。基线「无列车装甲」= `armorCars=armorTechLv=0`。

**`guardBoost`（权威结合式）**：

```
guardBoost = (1 + (有近战 ? 0.1 : 0)) × (有远程 ? 1.15 : 1)
# 双装备 → 1.1 × 1.15 = 1.265；禁止改成先乘后加或封顶 1.25
# 控物等异能对 guardBoost 的加算在本式之后（04 §8.3）
```

```
# 每回合：先算每人份额，再汇总（供 combat_drill 爆发）
对每名上场者 i：
  share_i = 守卫个体_i / max(Σ守卫个体, 1)     # 装甲战力不进个人份额
  burst_i = (本回合爆发成功 ? 1.6 : 1.0)
  outP_i  = P × rand(0.20,0.30) × share_i × (guardBoost_i×posOut_i) × burst_i
outP += Σ outP_i
outE += E × rand(0.20,0.30) × (ΣenemyBoost / max(敌数,1)) × (1 − min(0.15×上场人数, 0.60))
# 上式「人数减伤」≠ trainDR（碰撞减伤）≠ gear.defense（单兵受伤权重）

# enemyBoost：敌人模板字段，基线 1.0（配置 combat-targets；数值待阶段零校准）
# enduranceP / enduranceE：耐久系数，基线各 1.0（配置 balance.combatEndurance*；待校准）

progressP = ΣoutP / (E × enduranceE)
progressE = ΣoutE / (P × enduranceP)
```

结束：`progressP≥1` 或 `progressE≥1` 或满 4 回合；比较二者，高者胜；**相等 → 我方平局撤退**（§6.3：按弃物撤退处理临时堆）。

**`combat_drill` 双效果**（与 [04 §4.5](04-population.md) 同一专长，须同时实现）：  
① 被动：个体战力 ×1.05（已入 §4 守卫个体式）；  
② 爆发：每回合开始该人 `0.12` 检定，成功则本回合 `burst_i=1.6`（上式）；无专长不触发。埋点 `combat_burst_proc`。  
伤亡：按 §3.3 权重分摊 `outE`。  
后备顶上：**本回合伤亡结算后、下回合开始前**按 `reserve` 序填空槽；本回合已出手者不再补刀。
战后装备耗损见 §4。  
关系总修正：默认 **±20%**；`rally` Lv1 本场 **±25%**、Lv2 **±28%**（映射式见 [04 §6](04-population.md)）。  
临时堆：战败 / 平局撤退 / 选弃物撤退 → 按 [04 §5.4](04-population.md) 可被夺；非战斗成功路径见 §6.3。

## 9. 平衡验收

- 基线验收：无列车装甲战力（`armorCars=armorTechLv=0`）、**上场 1 人**、固定种子 1 万场 → 胜率 45–55%。**威胁标定**：守卫使 `P0` 达验收个体基线后，配置敌方威胁取 **`E = P0 / (1 − min(0.15×上场人数, 0.60))`**（1 人时 **`E ≈ P0/0.85`**），再代入 §7 回合式；**禁止**字面设 `P0=E` 却不乘人数减伤校准（否则约 9 成胜率）。人数减伤在正式战与验收中均启用。  
- 提高 P、上场人数、装备或合理占位（远程后排等）→ 胜率不降  
- D 不进 L2/L3 回合胜负；仅用于 L1/非战斗检定；无有效编队时非战斗 `D=0`；无 weaponKits 扁平项  
- ≥2 条有效非战斗路径（谈判/绕行/鸣笛均有成功与失败）；零资源可徒步撤离；成功保留临时堆（撤离除外）  
- 编队预设 ≤4；上场 ≤8；前后排修正可复算  
- 列车装甲 ≠ gear.defense
